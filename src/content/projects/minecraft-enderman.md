## Development

My work includes the enemy behavior, animation hooks, visual effects, item behavior, and network-aware interactions. The mod uses C#, BepInEx, and the R.E.P.O. modding toolchain, with Unity assets registered through REPOLib.

This is a fan-made mod for R.E.P.O., inspired by Minecraft; it is not an official release from either game's creators.
